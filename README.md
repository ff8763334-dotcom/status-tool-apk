# أداة الحالة — تطبيق أندرويد أصلي (Kotlin)

تطبيق حقيقي (APK) بتبويبين: تزيين الحالة قبل نشرها، وحفظ حالات جهات الاتصال. لا يلمس واتساب نفسه إطلاقاً.

## كيف يُجمَّع APK بدون أي أدوات عندك؟

عندما ترفع هذا المشروع على GitHub، سيعمل ملف `.github/workflows/build-apk.yml` تلقائياً: يفتح GitHub جهازاً افتراضياً، يُثبّت جافا وAndroid SDK وGradle، ثم يبني التطبيق ويحفظ ملف APK جاهزاً — **دون أن تحتاج Android Studio أو أي برنامج على جهازك.**

## الخطوات

### 1. رفع المشروع
1. افتح github.com وسجّل الدخول.
2. **New repository** → اسمِّه مثلاً `status-tool-apk` → اختر **Public** → **Create repository**.
3. اضغط **uploading an existing file** وارفع **كل** الملفات والمجلدات الموجودة هنا، محافظاً على نفس هيكلة المجلدات تماماً (خصوصاً `.github/workflows/build-apk.yml` و`app/`).
4. اكتب أي رسالة واضغط **Commit changes**.

> ⚠️ مهم: مجلد `.github` يبدأ بنقطة وقد يُخفيه متصفح الملفات عندك أثناء الرفع من الهاتف. إن لم يظهر، ارفع المشروع من حاسوب، أو أنشئ الملف يدوياً من داخل GitHub نفسه (Add file → Create new file) والصق المسار كاملاً: `.github/workflows/build-apk.yml`.

### 2. مشاهدة عملية البناء
1. اذهب لتبويب **Actions** أعلى المستودع.
2. ستجد عملية باسم "Build APK" تعمل تلقائياً (أو اضغط **Run workflow** لتشغيلها يدوياً).
3. انتظر 2–4 دقائق حتى تظهر علامة ✅ خضراء.

### 3. تحميل ملف APK
1. اضغط على عملية البناء المكتملة (✅).
2. انزل لأسفل الصفحة إلى قسم **Artifacts**.
3. اضغط على **status-tool-apk** لتحميله (سيأتي كملف zip يحتوي على `app-debug.apk` بداخله).

### 4. التثبيت على الهاتف
1. فُك الضغط عن الملف واستخرج `app-debug.apk`.
2. انقله إلى هاتفك (عبر الكابل، أو ارفعه لنفسك على Google Drive وحمّله من الهاتف).
3. عند فتحه سيطلب أندرويد تفعيل **"تثبيت من مصادر غير معروفة"** لمرة واحدة — وافق.
4. التطبيق سيُثبَّت بأيقونته الخاصة على شاشتك الرئيسية مثل أي تطبيق عادي.

## ملاحظات
- هذا بناء **Debug** (غير موقّع بمفتاح نشر رسمي) — يعمل بشكل كامل على جهازك، لكنه غير مخصص لرفعه على متجر Google Play.
- لتعديل أي شيء في التصميم أو الألوان لاحقاً، عدّل الملفات داخل `app/src/main/`، وادفع (commit) التعديل — سيُعاد البناء تلقائياً.
- إن ظهر خطأ في عملية Actions، افتح السجلّ (الخط الأحمر) وأرسل لي نص الخطأ بالضبط لأصلحه.

## الملفات الرئيسية
- `app/src/main/java/com/statustool/app/MainActivity.kt` — الشاشة الرئيسية والتبويبان
- `app/src/main/java/com/statustool/app/DrawingView.kt` — محرك رسم النص والملصقات والإطارات فوق الصورة
- `app/src/main/java/com/statustool/app/StatusAdapter.kt` — عرض وحفظ حالات جهات الاتصال من المجلد المختار
